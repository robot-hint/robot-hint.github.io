# HINT

Project page for **HINT: Human-Intent Inception for Long-Horizon Robot Manipulation**.

Repository: [robot-hint/robot-hint.github.io](https://github.com/robot-hint/robot-hint.github.io)

## Development

Requires Node.js 24 or later.

```bash
npm install
npm run dev
```

Build the static site with:

```bash
npm run build
```

Pushes to `main` are deployed automatically with GitHub Pages.
